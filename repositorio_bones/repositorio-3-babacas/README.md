1. Nome da empresa e do sistema

Empresa: Industrias BJB
Sistema: Sistema BJB

2. Descrição do sistema

A Sistem BJB é um sistema desenvolvido para auxiliar no gerenciamento de uma indústria de bonés. Ele tem como finalidade organizar as informações da empresa, facilitando o controle de produtos, funcionários, estoque, pedidos e produção.

3. Objetivo e problema que pretende resolver

O objetivo do sistema é melhorar a organização e o gerenciamento dos processos de uma indústria de bonés.
O sistema pretende resolver problemas como:
Falta de controle do estoque.
Dificuldade no gerenciamento de pedidos.
Desorganização das informações dos funcionários.
Dificuldade para acompanhar a produção.
Demora para consultar informações dos produtos.

4. Principais funcionalidades

Cadastrar funcionários.
Cadastrar produtos.
Cadastrar fornecedores.
Consultar produtos.
Listar funcionários.
Controlar o estoque de bonés.
Registrar pedidos.
Acompanhar a produção.
Editar informações cadastradas.
Consultar dados da empresa.

5. Tecnologias utilizadas

Visual Studio Code: ambiente utilizado para desenvolver o sistema.
HTML: estrutura das páginas.
CSS: aparência e estilização.
Banco de dados: armazenamento das informações.
